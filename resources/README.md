# resources

Static assets used by this repository's own documentation.

## What

`terminal.png` is the screenshot of the zsh/starship/tmux setup embedded at the top of the root
[`README.md`](../README.md).

## How

Not installed anywhere — it's referenced directly by its relative path (`resources/terminal.png`) from
Markdown in this repo, so it just needs to stay in this directory for that link to resolve.

## When

Rendered whenever the root `README.md` is viewed (e.g. on GitHub).

No keybindings or shortcuts apply; this directory holds documentation assets, not program configuration.
